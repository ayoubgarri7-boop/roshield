Vérificateur de lien

Ce lien est-il officiel?

Colle le lien qu'on t'a envoyé. Le site l'analyse sans jamais l'ouvrir : tout se passe dans ton navigateur, rien n'est envoyé nulle part.

Que faire si j'ai déjà cliqué ?

  1. Ne tape rien sur la page : ni mot de passe, ni code reçu, et ne télécharge rien. Ferme-la.
  2. Change ton mot de passe depuis l'application officielle (pas depuis un lien), sur un appareil de confiance.
  3. Déconnecte-toi de toutes les sessions dans les paramètres de sécurité de ton compte.
  4. Active la validation en 2 étapes si ce n'est pas déjà fait.
  5. Si tu as lancé un fichier, préviens un adulte : l'appareil doit être vérifié avec un antivirus.

Comment lire un lien toi-même

Dans https://www.roblox.com/games, le vrai site est roblox.com : les deux derniers morceaux avant le premier « / ». Dans https://roblox.com.example.com/login, le vrai site est example.com, même si « roblox.com » est écrit au début.
