Privacy

How it works, and what stays with you.

This page simply explains what the link checker does, what stays on your device, and what may be sent.

In short

  • Your link is checked on your device. Only an “unknown” (yellow) result may cause the full link to be sent, never a red or green result.
  • An additional check with VirusTotal is possible. Its status (on or off) is shown below. When it is on, the full link may be sent, only for a yellow result.
  • A result is never proof, and VirusTotal can only make a result worse, never turn it green.

Last updated: October 6, 2026

How the checker decides

It only reads the text of the link, on your device. It never opens the link. It looks at the real domain name (the end of the name, before the first “/”), compares it with the official Roblox and Discord domains, and looks for the usual tricks: deliberate typos, numbers instead of letters, an official name copied into the link, link shorteners... It answers with one of three levels: green (official domain), yellow (unknown domain) or red (probably a fake link). A result is never proof: if you’re ever unsure, talk to a trusted adult.

What stays on your device

The result is worked out on your device. The full link is sent only for an “unknown” (yellow) result, as explained below. A red or green result sends nothing. This site uses no accounts, no audience measurement and no ads. This site does not set any cookie itself and keeps nothing in your browser (nothing in its code is meant for that). Its hosts and the services that provide the fonts (GitHub Pages, Cloudflare, Google Fonts) may use their own techniques, which we don’t control.

The list of reported links

Your browser downloads a file from the site (js/blocklist.json), like any other page or image. It contains domain names and links already reported in the public list Phishing.Database (MIT license, text in the file LICENSE-PHISHING-DATABASE). The list is the same for everyone, and the comparison happens on your device. A list can be wrong and a link may have been cleaned up since: “reported” doesn’t mean “proven”.

The additional check (VirusTotal)

Status of this check on this site: …

When it is on, it applies only to a yellow (“unknown”) result, never to a red or green one. It is never used for an IP address, a local name or an official domain. The site sends a small RoShield service the full link (for example https://example.com/page), without the part after “#” and, except for a shortened link, without the query parameters (what follows “?”). The link must be https, at most 200 characters, with no username or port. If that isn’t possible (an http or too long link), only the domain name may be sent, never for a shortened link. That small service asks VirusTotal, a site that gathers the opinions of many security engines.

With 0 “malicious” engines, the result stays yellow, with a line saying that no antivirus flags it for now, which doesn’t mean it’s safe.

The answer can only make what you see worse, never turn it green:

  • 0 “malicious” engines: nothing changes. No reports doesn’t mean safe.
  • At least 1 “malicious” engine: the result stays yellow but becomes a strong warning, with the number of engines.
  • At least 2 “malicious” engines: the result turns red, with the exact number of engines.

Only “malicious” engines count (not “suspicious”, not “undetected”). Engines are sometimes wrong. If the small service doesn’t answer or a limit is reached, the checker works exactly as before, with its local result and a line saying so.

What the small service keeps

To respect VirusTotal’s limits, it keeps very little, and only for the time shown:

  • One result per domain name: a secret fingerprint of the name (never the name itself), a few numbers and a date. 6 hours if VirusTotal knows the domain, 2 hours if not.
  • One result per link: a secret fingerprint of the link (never the link itself), a few numbers and a date. 1 hour only, because a link’s destination can change.
  • One counter per visitor: a secret fingerprint of your IP address (never the address itself), which changes every day. 1 minute for the per-minute counter, until the end of the day (24 hours at most) for the daily one.
  • General counters (number of calls to VirusTotal), with no personal data: 1 minute and 1 day.

Limits: 4 calls per minute and 500 per day for everyone (VirusTotal’s free quota), 2 per minute and 30 per day for you (checking a link counts as 2). The small service keeps no IP address, no links, no paths. When something breaks, it writes only a short technical cause (for example “timeout”), never a link, a domain name or an IP address. An automatic cleanup deletes anything that has expired every hour.

What VirusTotal sees

VirusTotal receives the full link (or, as a fallback, the domain name) and the small service’s address (not yours). In the warning on its documentation page about the API (“Get a domain report”), VirusTotal writes that any item submitted or queried via the API will be “scanned and added to the VirusTotal dataset” and become accessible to its community. A queried domain name may therefore become visible there. That’s why the part after “#” and, except for a shortened link, the query parameters are never sent. The rest of the link may be kept by VirusTotal and shared with the security community. So don’t paste a link that contains anything private. Read VirusTotal’s documentation.

What the hosts see

Like any website, this one is served by a host (GitHub Pages or Cloudflare), which sees your IP address when you load a page. The fonts (Inter and Plus Jakarta Sans) are loaded from Google Fonts: Google sees your IP address at that moment. The small service runs on Cloudflare, which sees requests like any host does; that can’t be turned off.

A question or a mistake?

Does a result look wrong, or do you see a mistake on this page? Open an issue on the site’s GitHub repository: github.com/ayoubgarri7-boop/roshield/issues. Those pages are public: don’t write any password, code you received, or personal information there.
